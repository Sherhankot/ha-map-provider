# ha-map-provider

Меняет тайлы встроенной карты Home Assistant (`ha-map`) на 2ГИС, Яндекс
или OpenStreetMap, без пересборки фронтенда. Действует везде, где HA рисует
карту сам: панель «Карта», карта в окне персоны или трекера, штатная
карточка Map, редактор зон.

Провайдеры: `2gis` (по умолчанию), `yandex` и `osm`. Провайдер задаётся
параметром `?provider=` в адресе модуля.

## Совместимость

| HA | Как устроена карта | Что делает модуль |
|---|---|---|
| до 2026.8 | Leaflet, растровые тайлы CARTO | Подменяет слой CARTO |
| 2026.9 | Leaflet с векторной подложкой MapLibre, запасной растровый слой | Не даёт загрузиться векторному стилю, HA переходит на растр, модуль подменяет его |
| 2026.10 | Движок MapLibre, запасной движок Leaflet | Переводит карты на движок Leaflet и подменяет его растровый слой |

Модуль написан по исходникам фронтенда `20260304.0` (HA 2026.3.1),
`20260826.7` (HA 2026.9.4) и `20260930.0` (бета HA 2026.10). На живом HA
проверен только 2026.3.1.

Модуль опирается на внутреннее устройство `ha-map` (`leafletMap`,
`update`, `_loadMap`, `_forceLeaflet`), а не на публичный API, поэтому
любое обновление HA может его сломать. Если модуль перестал действовать,
HA показывает свою штатную карту: сломаться сильнее она не должна.

## Установка

### Через HACS

1. В HACS откройте меню (три точки) → «Пользовательские репозитории»
   (Custom repositories). Добавьте URL этого репозитория с типом
   **Dashboard** (в старых версиях HACS - Lovelace или Plugin).
2. Найдите **HA Map Provider** и нажмите Download.
3. Добавьте в `configuration.yaml`:

   ```yaml
   frontend:
     extra_module_url:
       - /hacsfiles/ha-map-provider/ha-map-provider.js?provider=2gis
   ```

   Для Яндекса - `?provider=yandex`.

### Вручную

1. Скопируйте `ha-map-provider.js` в `/config/www/`.
2. Добавьте в `configuration.yaml`:

   ```yaml
   frontend:
     extra_module_url:
       - /local/ha-map-provider.js?provider=2gis
   ```

### После установки

1. Перезапустите HA и обновите страницу в браузере без кэша (Ctrl+F5).
2. Проверьте консоль браузера (F12): там должна появиться строка
   `ha-map-provider: base map -> 2gis`.
3. Мобильное приложение хранит фронтенд в своём кэше, его нужно сбросить
   и перезапустить приложение:
   - iOS: настройки приложения → Companion App → Debugging → Reset
     frontend cache;
   - Android: сведения о приложении в настройках системы → Хранилище →
     Очистить кэш.

### Почему `extra_module_url`

Ресурсы дашборда загружаются только вместе с дашбордом. Панель «Карта» и
окна персон живут вне дашбордов, поэтому модуль подключается через
`extra_module_url`, который загружается на любой странице.

HACS дополнительно регистрирует файл как ресурс дашборда, без
`?provider=`. Это не мешает: модуль применяет патч только один раз, а
провайдер из `extra_module_url` важнее значения по умолчанию. Если
`extra_module_url` загрузился позже ресурса (так бывает в мобильном
приложении), уже открытые карты переключаются на нужного провайдера. Но одного ресурса без
`extra_module_url` мало: на панели «Карта» и в окнах персон карта
останется прежней.

## Как работает

Модуль перехватывает регистрацию компонента `ha-map` и оборачивает его
метод `update`. После обновления компонента модуль находит штатный
растровый слой Leaflet (CARTO, прокси HA `/api/map_tiles/raster` или OSM),
переключает его через `setUrl` на выбранного провайдера и меняет
атрибуцию. Слои, добавленные позже, ловит по событию `layeradd`. При
первом открытии карты на долю секунды могут мелькнуть штатные тайлы.

Яндекс рисует тайлы в проекции EPSG:3395, а карта HA - в EPSG:3857. Между
ними почти чистый вертикальный сдвиг, поэтому модуль собирает каждый тайл
из одного-двух соседних тайлов Яндекса, сдвинутых на нужное число
пикселей. Погрешность внутри тайла - меньше пикселя. Тайлы остаются
обычными `<img>`, так что CORS от сервера Яндекса не нужен.

## Ограничения

- С HA 2026.10 редактор зон остаётся на штатной карте: перетаскивать зоны
  умеет только движок MapLibre.
- С HA 2026.9 в тёмной теме HA инвертирует цвета растровой карты фильтром
  CSS - так он делает со своим запасным растром. Тёмной палитры у 2ГИС и
  Яндекса через модуль нет.
- Модуль берёт тайлы 2ГИС и Яндекса с публичных адресов, которые не
  описаны в документации и не требуют ключа. Провайдеры могут закрыть их
  без предупреждения. Условия Яндекса разрешают показывать его карты
  только через его API, так что прямое использование тайлов - на вашей
  ответственности. Официальные API обоих провайдеров требуют ключ.
