# ha-map-provider

Подменяет провайдера тайлов у встроенной карты Home Assistant (`ha-map`):
панель «Карта», карта в диалоге персоны/трекера, штатная карточка карты,
редактор зон. Без пересборки фронтенда.

Провайдеры: `2gis` (по умолчанию), `osm`.

## Совместимость

- Фронтенд на Leaflet-растре с тайлами CARTO: HA до 2026.8 включительно.
  Писалось по исходникам frontend `20260304.0` (HA 2026.3.1).
- С HA 2026.9 базовая карта рисуется MapLibre на векторных тайлах -
  модуль ничего не делает (не находит слой CARTO).
- Модуль опирается на внутренности `ha-map` (`leafletMap`, метод `update`),
  не на публичный API. Обновление HA может его сломать.

## Установка

### Через HACS

1. HACS → три точки → «Пользовательские репозитории» (Custom repositories):
   URL этого репозитория, тип **Dashboard** (в старых HACS - Lovelace/Plugin).
2. Найти **HA Map Provider** → Download.
3. В `configuration.yaml`:

   ```yaml
   frontend:
     extra_module_url:
       - /hacsfiles/ha-map-provider/ha-map-provider.js?provider=2gis
   ```

   HACS сам добавит файл и как ресурс дашборда - это не мешает, модуль
   ставит патч один раз. Но без `extra_module_url` карта в диалогах и на
   панели «Карта» не сменится.
4. Дальше - шаги 3-5 ручной установки ниже.

### Вручную

1. Скопировать `ha-map-provider.js` в `/config/www/`.
2. В `configuration.yaml`:

   ```yaml
   frontend:
     extra_module_url:
       - /local/ha-map-provider.js?provider=2gis
   ```

   Именно `extra_module_url`, а не ресурс дашборда: ресурсы грузятся только
   при открытии дашборда, а панель «Карта» и диалоги - вне дашбордов.
3. Перезапустить HA, в браузере обновить страницу без кэша (Ctrl+F5).
4. В консоли браузера (F12) должна быть строка
   `ha-map-provider: base map -> 2gis`.
5. Мобильное приложение кэширует фронтенд: после установки сбросить его
   кэш (iOS: Настройки приложения → Companion App → Debugging → Reset
   frontend cache; Android: сведения о приложении → Хранилище → Очистить
   кэш) и перезапустить приложение.

## Как работает

`customElements.get("ha-map").prototype.update` оборачивается: после
каждого обновления компонента слой тайлов с URL `basemaps.cartocdn.com`
переключается через `setUrl` на тайлы выбранного провайдера, атрибуция
меняется. При первом открытии карты на долю секунды могут мелькнуть
тайлы CARTO.

## Ограничения

- Яндекс не поддержан: его тайлы в EPSG:3395, а карта `ha-map` создаётся
  в EPSG:3857 - маркеры съедут по вертикали. Нужна подмена CRS до создания
  карты, это отдельная задача.
- Тайлы 2ГИС - недокументированный бесплатный эндпоинт без ключа;
  официальный Raster Tiles API требует ключ.
