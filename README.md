# ha-map-provider

Меняет тайлы встроенной карты Home Assistant (`ha-map`) на 2ГИС или
OpenStreetMap, без пересборки фронтенда. Действует везде, где HA рисует
карту сам: панель «Карта», карта в окне персоны или трекера, штатная
карточка Map, редактор зон.

Провайдеры: `2gis` (по умолчанию) и `osm`.

## Совместимость

- Работает, пока встроенная карта рисуется Leaflet на растровых тайлах
  CARTO, то есть в HA до 2026.8 включительно. Модуль написан по исходникам
  фронтенда `20260304.0` (HA 2026.3.1).
- С HA 2026.9 карту рисует MapLibre на векторных тайлах. Модуль не находит
  слой CARTO и ничего не меняет.
- Модуль опирается на внутреннее устройство `ha-map` (поле `leafletMap`,
  метод `update`), а не на публичный API, поэтому любое обновление HA может
  его сломать.

## Установка

### Через HACS

1. В HACS откройте меню (три точки) → «Пользовательские репозитории»
   (Custom repositories). Добавьте URL этого репозитория с типом
   **Dashboard** (в старых версиях HACS - Lovelace или Plugin).
2. Найдите **HA Map Provider** и нажмите Download.
3. Добавьте в `configuration.yaml`:

   ```yaml
   frontend:
     extra_module_url:
       - /hacsfiles/ha-map-provider/ha-map-provider.js?provider=2gis
   ```

### Вручную

1. Скопируйте `ha-map-provider.js` в `/config/www/`.
2. Добавьте в `configuration.yaml`:

   ```yaml
   frontend:
     extra_module_url:
       - /local/ha-map-provider.js?provider=2gis
   ```

### После установки

1. Перезапустите HA и обновите страницу в браузере без кэша (Ctrl+F5).
2. Проверьте консоль браузера (F12): там должна появиться строка
   `ha-map-provider: base map -> 2gis`.
3. Мобильное приложение хранит фронтенд в своём кэше, его нужно сбросить
   и перезапустить приложение:
   - iOS: настройки приложения → Companion App → Debugging → Reset
     frontend cache;
   - Android: сведения о приложении в настройках системы → Хранилище →
     Очистить кэш.

### Почему `extra_module_url`

Ресурсы дашборда загружаются только вместе с дашбордом. Панель «Карта» и
окна персон живут вне дашбордов, поэтому модуль подключается через
`extra_module_url`, который загружается на любой странице.

HACS дополнительно регистрирует файл как ресурс дашборда. Это не мешает:
модуль применяет патч только один раз. Но одного ресурса без
`extra_module_url` мало: на панели «Карта» и в окнах персон карта
останется прежней.

## Как работает

Модуль оборачивает метод `update` компонента `ha-map`. После каждого
обновления компонента он находит слой тайлов с `basemaps.cartocdn.com`,
переключает его через `setUrl` на выбранного провайдера и меняет
атрибуцию. При первом открытии карты на долю секунды могут мелькнуть
тайлы CARTO.

## Ограничения

- Яндекс не поддерживается. Его тайлы в проекции EPSG:3395, а `ha-map`
  создаёт карту в EPSG:3857, и маркеры съедут по вертикали. Чтобы это
  исправить, нужно подменить проекцию до создания карты. Это отдельная
  задача.
- Модуль берёт тайлы 2ГИС с публичного адреса, который не описан в
  документации и не требует ключа. 2ГИС может закрыть его без
  предупреждения. Официальный Raster Tiles API требует ключ.
